# Content rating (IARC questionnaire) and target audience

## Content rating questionnaire (Play Console → App content → Content rating)
Category: **Game**. Suggested answers for Gatefall as it is in version 47; answer honestly from what the game
actually shows when you fill it in.

| Topic | Answer | Notes |
|---|---|---|
| Violence | **Yes, fantasy violence** | Pixel-art monsters attack and are "destroyed"; no blood, no gore, no realistic humans hurt. When asked: violence is unrealistic / fantasy, not graphic, not against realistic humans. |
| Blood / gore | No | |
| Fear / horror | Possibly mild | Boss monsters (a necromancer, a dragon) in pixel art. Answer "no" unless a question explicitly covers mild fantasy monsters. |
| Sexuality / nudity | No | Check card art once more before submitting. |
| Language | No profanity in the game's text | Player names typed by others are user content, see below. |
| Controlled substances | No drugs, alcohol or tobacco | Note: the card "Red Bull" names an energy drink (see `IP-REVIEW.md`). |
| Gambling | No real-money gambling, no simulated gambling, no loot boxes | The d20 roll for who goes first is not gambling. |
| User interaction | **Yes** — users can interact online | Players see each other's chosen names in private rooms joined by code. There is no chat, no friend list, no public matchmaking. |
| Shares user location | No | |
| Digital purchases | No | |
| Unrestricted internet | No | |

Expected result: roughly **PEGI 7 / ESRB Everyone 10+ / USK 6** with "Fantasy violence" and an
"Users interact" notice. The questionnaire decides; resubmit it whenever content changes.

## Target audience (Play Console → App content → Target audience and content)
Recommended: **13 and over** (13–15, 16–17, 18+).

Choosing any age under 13 puts the app under Google's **Families policy**: stricter rules on ads, data and
user interaction (online rooms where children see strangers' typed names would need extra safeguards), and
possibly a teacher-approved review. If you want a kids audience later, plan that as its own step.

When asked whether the app could unintentionally appeal to children: the pixel style might; answer honestly
and explain that there are no ads, no purchases, no chat and only private room codes.

## User-generated content
The only user-generated content is the player name (max 24 characters) shown to the other players in a room
the player chose to join. Google's UGC policy expects a way to deal with abuse where users can see each other's
content. Because rooms are private (code-only) and there is no chat, this is low-risk; a simple name filter or
"mute names" option would be a good addition before a public matchmaking feature is ever added.
